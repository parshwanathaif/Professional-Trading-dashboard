# Reference data

Put verified reference files here before importing them:

- `holidays_nse_<year>.csv`: from the official NSE "Trading holidays for the calendar year" circular. Columns: date, exchange, description, source, verified. Mark Muhurat or other special sessions with description `special session`.
- `price_bands_<date>.csv`: from the exchange price-band files, if your licence permits.

No real holiday file ships with the platform, because the list must come from the current official circular.
